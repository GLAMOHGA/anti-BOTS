# Telegram Anti-Nakrutka (Анти накрутка ТГ) Антинакрутка

Утилита для поиска и удаления накрученных ботов из каналов и чатов Telegram. Создано с помощью ИИ. Работает только на ПК через терминал.

## Как это работает

Скрипт заходит на ваш аккаунт (по коду или QR) и анализирует Admin Log чата/канала. Он ищет системные записи о вступлении (кто зашёл, кого пригласили, кто зашёл по ссылке или заявке).

Если за короткий промежуток времени (например, минуту) таких вступлений аномально много (20 вместо обычных 1-2), скрипт понимает — это накрутка, и сообщает вам. Через терминал вы выбираете действие: кикнуть или забанить ботов. После этого скрипт может удалить системные сообщения о вступлении из чата.

> Если системных сообщений о вступлении нет — скрипт не сможет определить, кто зашёл, и не примет меры. Банит ваш аккаунт, поэтому вы должны быть админом в чате или канале.

## Установка и запуск

1. Установите зависимости:
   pip install -r requirements.txt
2. Запустите файл:
   python clean.py

Инструкция понятно написана прямо внутри самого софта. Запускаете файл в терминале и следуете указаниям.

## Возможности

- **Вход:** По коду или QR-коду (с поддержкой 2FA)
- **Поиск:** Волн накрутки через Admin Log
- **Действия:** Бан/кик ботов (с защитой от FloodWait)
- **Чистка:** Удаление системных сообщений о вступлении
- **Удобство:** Автоматический повторный вход через сохранённую сессию

# Telegram Anti-Nakrutka (Anti-Bot Tool)

A utility for finding and removing fake/inflated bot accounts from Telegram channels and chats. Created with the help of AI. Works only on PC via terminal.

## How it works

The script logs into your account (via code or QR) and analyzes the Admin Log of the chat/channel. It looks for system records of users joining (who joined, who was invited, who joined via link or request).

If within a short period of time (e.g., one minute) there is an abnormally high number of such joins (20 instead of the usual 1-2), the script identifies it as artificial inflation and notifies you. Through the terminal, you choose the action: kick or ban the bots. After that, the script can delete the system join messages from the chat.

> If there are no system join messages, the script won't be able to determine who joined and won't take action. It bans from your account, so you must be an admin in the chat or channel.

## Installation and Launch

1. Install dependencies:
   pip install -r requirements.txt
2. Run the file:
   python clean.py

The instructions are written clearly inside the software itself. Launch the file in the terminal and follow the prompts.

## Features

- **Login:** Via code or QR code (with 2FA support)
- **Detection:** Finding join surges via Admin Log
- **Actions:** Ban/kick bots (with FloodWait protection)
- **Cleanup:** Deleting system join messages
- **Convenience:** Auto re-login using a saved session
